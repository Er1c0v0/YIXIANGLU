# 阶段一、二开发计划

日期：2026-10-21。依据 [PRD](../PRD.md)；当前范围仅为阶段一、二的原型，不代表 v1.0 全量交付。

## 目标与边界

建立微信原生 TypeScript 工程，完成计算、会话及必要路由校验，以乾、坤、离、夬、兑五卦经过核对的真实资料跑通“生成本卦 → 阅读 → 选择变爻 → 查看变卦”。采用米白、深灰、古铜色；图鉴及速查只展示开发状态，不填虚假资料。完整资料、多维搜索、完整八卦速查、全面适配与体验版发布留到后续。

## 结构与行为

原生 Page、Component 和 TypeScript；纯计算、内容读取、页面交互分开。沿用 PRD 的 Trigram、SixLines、LinePosition、CastSession 与来源审核契约；完整元数据与渐进正文分离。数字接口按下卦、上卦、变爻接收字符串。爻数组下至上，显示上至下，卦序不充当二进制编码。

手动允许 0～6 爻，数字必须固定唯一爻，业务入口也约束此规则。内存会话支持返回保留输入、选择与阅读状态，新流程和重新生成重置结果。非法路由不以默认卦掩盖错误。正文和白话分开，按具体版本与段落定位核对，缺正文显示“资料整理中”。内容源在运行目录外构建为随包模块，本轮仅设置必要的构建与结构检查。

界面调整以最新需求为准：减少说明性文字；首页无角标、无入口编号，按钮独立反馈；数字框保持单行，隐藏计算过程；卦辞后紧接意象与整体含义，两区默认展开且可折叠；经传、爻辞仅展示原文，来源简洁。白话源资料与审核记录保留，不重新标记审核结果。
