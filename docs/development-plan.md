## 本轮完成条件

1. `npm run check`与调整后的`npm run check:content:release`通过；保留独立64组合、4096变化、数字边界、会话、搜索和必要拒绝检查。
2. 核对全部运行原文与来源未变，代表学习/搜索/速查流程编译复验通过；实际打包清单仅含程序核心内容。
3. 整理PRD、内容档案、验证记录和近期必要证据；检查暂存内容，提交并推送，核对远端提交一致。
4. 完成可用的开发版本上传，记录`0.1.0`、AppID和上传结果；用户待备案通过后自行设置体验版、提审或正式发布。上传与发布分开记录，不代替体验成员权限/使用验证。

## 后续维护

保留待审来源、异文与人工复核进度，按后续需要继续文献整理；不将用户取消的两项验收重新列为首版阻断。设备环境仅记录实际已知信息，不以“最新”推断具体版本或Android覆盖。发布后按实际反馈修复问题，不增加登录、后端、历史、收藏或新的检索功能。

产品规则见[PRD](PRD.md)，来源与待审见[资料核对](content-review.md)，内容维护见[内容说明](../content/README.md)。
