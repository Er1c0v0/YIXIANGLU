# 易象录产品与资料基线

第二版开发目标及验收已完成，已删除实施计划与逐项验收清单。本文件保留继续开发所需的行为契约和算法参照；课堂资料独立保存在 [content/classroom.md](../content/classroom.md)，不再作为需求正文。当前交付见 [README](../README.md)，未实施方向见 [体验探索](ux-exploration.md)。

## 1. 定位与范围

原生、离线的《易经》学习与课堂查询工具。现有范围为手动／数字生成、变爻分析、卦名检索与筛选、独立阅读、目录与连续翻阅、八卦速查；不包含原文全文检索、历史、收藏、笔记、账号、后端或个性化解读。新增范围须另行确定。

## 2. 查阅与观变

- 图鉴直接进入独立详情，不创建观变会话；合法编号 `/pages/detail/index?id=1` 可直接打开。非法编号提示返回图鉴，不默认乾卦；无图鉴返回栈时提供返回图鉴入口。
- 卦辞、意象与整体含义默认展开，彖传、大象传默认折叠；六爻按初爻至上爻独立折叠并可多开，每条包含爻辞、小象及共同来源。用九／用六独立展示。生成和分析页不增加整套六爻、目录或翻阅。
- 目录位于卦头下方并吸顶，使用底部 `page-container`。选择条目先关闭目录、展开目标，渲染后按目标位置与吸顶条实际高度滚动；其余条目不收起。六爻分区入口只定位，不展开全部六爻。
- 关闭或遮罩收起目录并保留阅读位置；面板打开时背景不滚动，长目录可滚动，底部避让安全区。支持的平台系统返回先关闭目录；鸿蒙原生微信返回拦截保留既有平台例外，按实际系统／微信版本验证，不以品牌推定。原依据为 [page-container 说明](https://developers.weixin.qq.com/miniprogram/dev/component/page-container.html)。
- 无筛选或直接编号进入时按全量卦序翻阅；筛选入口先完成待刷新搜索，再保存当前有序结果快照。所点卦已不在最新结果时留在列表；明确传入但失效的上下文提示返回图鉴，不扩大阅读范围。
- 上一／下一项在同一详情页换卦，首尾禁用、不循环。换卦回到顶部，重置正文／来源展开与目录；返回图鉴保留原条件和位置，不滚到最后读过的卦。
- 点击“观察变化”才为当前卦建立空选择会话并进入变爻页。返回保留阅读状态与选择，同页再次观察复用有效会话；换卦、卸载或旧会话被替代后重新开始。只结束本页所属会话，不清空其他流程；阅读展开与选择变爻分开管理。

## 3. 界面基线

沿用现有 [全局样式](../miniprogram/app.wxss) 与组件：米白底、深灰正文、古铜强调，系统字体，页面／卡片间距与触控反馈保持一致。页面首节点使用 `page-meta root-font-size="system"`，文字用 rem 跟随微信字体设置，布局用 rpx；主要按钮至少48px高，长文与按钮自然换行，选择和展开状态不只依赖颜色。

经传、爻辞、小象、特殊条文、摘要及意象／整体含义使用可长按选取的 `text`。意象与整体含义按原顺序以空行连接到同一节点，支持整段复制；不增加逐卡复制按钮。来源只显示文献标题、章节定位及复制链接，完整版本与权利说明留档。新增界面沿用既有结构，不加入装饰、重复操作或开发说明。

## 5. 继承的产品与资料基线

本节承接仍有效的约定及独立参照，不是第一版待办。既有审核状态不因PRD换版提高；2026-10-22用户取消的首版文献人工复审和真机性能计时不重新列为阻断，也不改为“通过”。

### 5.1 学习定位与资料

产品展示原典中的文字，辅助识卦、读辞和观察变化，不生成个人运势、主爻判断或吉凶决策。经传、爻辞及特殊条文只展示原文；既有意象与整体含义继续展示，白话、注记和审核留在内容档案。

现有64卦包括卦辞／彖传／大象传各64块、384条爻辞及384条小象、乾坤各2块特殊原文，共964块。原文与来源按ID关联，采用版本、异文及待审以[资料核对](content-review.md)为准；修改内容须按[内容维护](../content/README.md)更新受影响记录，不得因界面或工程整理批量改字或改审核状态。

### 5.4 数字输入与取余

三个字段依次为下卦数、上卦数、变爻数。输入先去首尾空白，只接受含非零位的ASCII十进制数字串；允许前导0，拒绝空、全0、负数、小数、正号、指数、字母、内部空白及全角数字。

按字符迭代`r = (r × 10 + digit) % divisor`，分别对8、8、6取余；余0对应8、8、6。不得把整个字符串转为Number、把三数相加或加入时间／随机数。运行算法额外空间O(1)，BigInt只用于开发测试独立参照。数字模式始终只允许计算出的唯一固定爻，领域入口同样校验。

### 5.5 变爻与生成流程

手动／图鉴观变允许0～6爻；集合只含1～6整数，去重排序。相对本卦同时翻转所选位，未选位不变；`changedMask = originalMask XOR OR(1 << (p-1))`。零变保持本卦，全变翻转六位，同一集合变两次复原。

爻名按本卦阴阳和位置决定：阳用九、阴用六，位置1为初、6为上，其余为二三四五。分析展示本卦所选爻辞及小象，不替换为变卦同位爻辞；用九／用六独立展示，不判定占断依据。手动／数字生成仍先读本卦，数字爻不可改选；新生成清空旧结果，返回保留当前有效会话。非法观变路由明确提示重新生成，不默认乾卦。

### 5.6 图鉴检索与速查

图鉴支持简繁卦名、全称、登记别名、拼音、首字母和精确卦序；规范化大小写、声调、空格与ü输入变体。数字只精确匹配卦序；关键词、上卦、下卦取交集，结果按卦序排序。输入延迟150ms刷新且不回写组词，清除只去关键词，重置清空全部条件。条件与滚动位置在本次内存保留；无结果保留输入与筛选并显示明确提示。

八卦速查保持两行八卦选择、类别筛选、卦性置顶；展示课堂8类、五行、颜色与两栏生克。卦性统一简体及同义显示（順／動／麗／說→顺／动／丽／悦），按展示值去重；原典原词和审核继续留档，不据此改写文献。页面不重新加回来源／体系说明小字、先天数或先天方位。
