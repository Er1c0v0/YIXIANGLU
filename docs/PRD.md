## 1. 目标与范围

### 1.1 要解决的问题

第一版从图鉴查到某卦后，进入带“第二步 · 先读本卦”的生成流程；查某一爻的原文需要选爻再进入分析，连续看其他卦还需返回列表。本版让用户在独立详情中完成阅读、定位与翻阅，主动点击“观察变化”时再进入既有观变流程。

| 用户任务 | 本版完成路径 |
| --- | --- |
| 查乾卦九五的爻辞与小象 | 图鉴 → 乾卦详情 → 目录中的九五 → 原文与来源 |
| 顺序阅读经传和六爻 | 图鉴 → 详情 → 展开所需段落 → 上一卦／下一卦 |
| 在一组筛选结果中复习 | 图鉴筛选 → 详情 → 上一结果／下一结果 → 返回原列表位置 |
| 阅读后观察某些爻的变化 | 详情 → 观察变化 → 选择变爻 → 分析 → 返回阅读 |

### 1.2 本版功能边界

| 纳入本版 | 本版不增加 |
| --- | --- |
| 图鉴专用详情，按卦编号直接读取本地资料 | 新的首页布局、一级导航或全局视觉主题 |
| 六爻独立展开，原文、小象及共同来源面板 | 新的白话译注、原文改写、逐爻本变卦对照 |
| 吸顶目录入口、章节／爻位展开定位 | 点击卦头微型爻线、手势翻页、自动播放、复杂动效 |
| 全量卦序或当前筛选结果内连续翻阅 | 全文搜索、类象反查、八卦横向对照、练习 |
| 本页阅读状态与观变返回衔接 | 收藏、历史、笔记、分享、跨次继续阅读 |
| 与原有风格一致的小屏及放大字体适配 | 字号设置页、登录、后端、云同步、支付 |

完整六爻、目录和翻阅只在图鉴详情启用。手动／数字生成继续先读本卦再观变；分析页不追加整套六爻或连续翻阅控件。现有原文、计算与八卦速查采用第5节基线。

## 2. 页面与交互需求

### 2.1 独立查阅（V2-R01）

- 图鉴点击某卦进入独立详情，原生导航栏显示该卦全称；正文沿用卦序、全称、上下卦、卦形和简要含义。
- 查阅页不显示生成步骤编号，不要求生成结果或观变会话。展开章节、爻辞及来源都只是阅读操作。
- 从图鉴进入时，原生返回回到图鉴，保留进入前的关键词、上下卦筛选、结果和滚动位置。
- 有效卦编号可独立打开；没有图鉴返回栈时提供“返回图鉴”入口，不假设存在上一页。缺失、越界或非法编号显示“未找到该卦”和“返回图鉴”，不默认乾卦。
- 页面中的卦头、原文、爻名、目录、来源、导航标题及观变入口始终对应当前正在阅读的卦。

### 2.2 阅读结构与六爻（V2-R02）

| 顺序 | 内容 | 初始状态 |
| --- | --- | --- |
| 1 | 卦头：卦序、卦名、上下卦、卦形与简要含义 | 显示 |
| 2 | 阅读目录入口 | 显示，滚动到顶部时吸顶 |
| 3 | 卦辞原文 | 展开 |
| 4 | 意象与整体含义 | 展开 |
| 5 | 彖传原文 | 折叠 |
| 6 | 大象传原文 | 折叠 |
| 7 | 六爻：初爻至上爻的六个独立条目 | 爻名均显示，正文均折叠 |
| 8 | 用九／用六及相关象传 | 仅乾／坤出现，折叠 |
| 9 | 上一卦／下一卦与“观察变化” | 位于正文末尾，随页面滚动 |

六爻区域使用一个分区标题和六个独立折叠条目，不增加外层总折叠。每条标题取当前卦的实际爻名，如初九、六二、上六；展开后依次显示“爻辞原文 → 小象传原文 → 来源”。来源面板同时包含两段各自的定位，默认关闭。

所有文献来源统一仅显示文献标题、章节定位和“复制来源链接”；不展示版本长说明、权利／免责说明或引用备注。完整来源及审核资料继续保留在内容档案中。

- 允许多条同时展开，打开一条不关闭其他条；再次点击该条标题只收起本条。
- 正文按初爻到上爻排列；卦形保持上爻到初爻绘制，沿用既有方向约定。
- 阅读爻辞不改变卦象、不勾选变爻、不继承数字模式的固定选择。
- 用九／用六独立于六个爻位，保留原文与对应象传，不作为第七爻。
- 经传、爻辞、小象及特殊条文原文，以及卦头摘要、意象与整体含义正文均须支持长按选取，实际实现与设备验证状态见验证记录；不新增逐卡复制按钮、说明段落、标签或默认展开的出处详情。

### 2.3 目录与定位（V2-R03）

正文只有一条轻量的“阅读目录”入口，放在卦头下方。向下阅读时贴在原生导航栏下，不重复显示一整套卦头或增加固定底部工具栏。

点击后打开底部目录面板：

| 入口 | 定位结果 |
| --- | --- |
| 卦辞、意象与整体含义、彖传、大象传 | 展开目标章节并定位到标题 |
| 六爻 | 定位到六爻分区标题，不自动展开全部爻辞 |
| 六个具体爻名 | 展开对应条目并定位到该爻标题 |
| 用九／用六 | 仅乾／坤显示；展开并定位到对应特殊条文 |

六个爻名直接排列在目录的“六爻”项下，使用可换行的文字按钮，不增加第二层弹窗。目录选中后自动收起；其余章节及爻的展开状态不变。选择已展开项只定位，不反向收起。

定位完成后，目标标题与内容开头可见，不被吸顶栏挡住；靠近页尾时允许停在最大滚动位置，不靠大块空白强行顶齐。目录内长内容可滚动，保留底部安全区。点击遮罩或“关闭”收起面板并留在原阅读位置。目录打开时，背景正文不跟随滚动。

支持拦截返回的平台，系统返回优先关闭面板，面板关闭后再按正常页面路径返回。鸿蒙原生微信暂不支持该拦截，系统返回遵循平台行为，用户仍可通过“关闭”或遮罩收起目录；本版保留底部面板，不改为独立目录页。此例外依据[微信官方 page-container 说明](https://developers.weixin.qq.com/miniprogram/dev/component/page-container.html)，验收按实际系统及微信版本分别记录，不仅凭设备品牌判断。

### 2.4 连续阅读（V2-R04）

| 进入详情时的条件 | 阅读范围与顺序 | 按钮文案 |
| --- | --- | --- |
| 无有效关键词、无上下卦筛选 | 全部64卦，按通行卦序 | 上一卦／下一卦 |
| 有有效搜索或筛选条件 | 完成最新搜索后的结果快照，保持图鉴现有顺序 | 上一结果／下一结果 |
| 通过合法编号直接打开，未携带列表上下文 | 全部64卦，以当前编号为位置 | 上一卦／下一卦 |

- 按钮附目标卦全称，可换行；无上一项／下一项时禁用对应按钮，不首尾循环。单个结果时两侧均禁用。
- 点击结果时若有尚未执行的150ms搜索刷新，先按最新关键词与筛选条件完成刷新；所点卦仍在最新结果中才进入详情，否则留在更新后的图鉴，不使用旧列表或自动打开其他卦。
- 搜索与筛选结果在上述刷新完成后、进入详情前固定；读下一项不会改变图鉴的搜索条件或列表滚动位置。
- 切换在同一详情页完成，不连续压入页面栈。从图鉴进入并连续翻阅后，一次原生返回仍回到图鉴；列表不自动滚到最后阅读的卦。直接编号入口的返回按§2.1处理。
- 切换后回到卦头，章节、六爻与来源恢复初始折叠状态，目录关闭；不为之前读过的每一卦保存展开状态。
- 观变使用切换后的当前卦，不能继续使用首次进入详情的路由编号。
- 已明确传入但失效或与当前卦不匹配的查阅上下文，提示“本次查阅已失效，请返回图鉴”，不静默扩大为全部64卦。

### 2.5 观变衔接与状态（V2-R05）

“观察变化”是详情页末尾唯一主操作，首次点击时以当前卦建立图鉴观变会话，直接进入既有变爻页，初始不选爻；不再重复经过本卦阅读页。之后仍允许选择0～6爻，确认后进入既有分析页。

图鉴路径的变爻页与分析页分别显示“观察爻变”和“阅读变化”，去掉“第三步／第四步”编号；手动与数字生成路径保留原步骤编号。

| 操作 | 阅读状态 | 观变状态 |
| --- | --- | --- |
| 新进入一卦详情 | 使用默认展开状态与顶部位置 | 不创建会话 |
| 展开正文／来源、使用目录 | 保留当前页其他状态 | 不创建或改变会话 |
| 同一详情首次点击“观察变化” | 保留当前展开项和滚动位置 | 为当前卦新建会话，选择为空 |
| 分析返回变爻，再返回详情 | 恢复当前卦阅读状态；目录保持关闭 | 保留本次选择 |
| 同一详情再次点击“观察变化” | 保留阅读状态 | 本页关联会话仍有效时继续原选择 |
| 切换上一项／下一项 | 换卦并恢复默认阅读状态 | 结束本页上一卦的观变关联，下次观察重新开始 |
| 返回图鉴等操作卸载详情后重新进入，或程序重启 | 不恢复跨次历史 | 不恢复已结束的本次观察 |

单纯查阅不覆盖其他生成流程的会话；主动开始新观察仍遵循“新流程清空旧结果”。前往变爻或分析页只暂时隐藏详情，不结束关联；换卦或详情卸载时，只结束仍属于本页的关联会话，不清空其他流程的会话。本页原关联会话若已被新流程替代，重新观察从空选择开始，不复活旧结果。阅读状态与选爻状态分别维护，不把“展开了哪一爻”当作“选择了哪一爻”。

## 3. 延续现有设计语言（V2-R06）

**新增设计必须延续原小程序的整体风格，并保持简洁。优先复用已有布局、样式和组件；每个新增元素都应直接服务阅读、定位或翻阅，不能为“第二版”增加装饰或功能入口。**

### 3.1 视觉基线

以当前[全局样式](../miniprogram/app.wxss)和阅读组件为准，沿用现代简约、米白底色与少量古铜强调。字号以微信字体16px及原375px宽度的视觉比例为基线，使用rem随微信字体设置缩放；布局间距继续使用rpx。

| 项目 | 沿用要求 |
| --- | --- |
| 页面／卡片 | 页面`#F7F4ED`，卡片`#FFFDFA`；细边框`#DDD6C9` |
| 文字／强调 | 主文字`#292824`，辅助文字`#625D55`，主操作及必要强调`#765535` |
| 字体 | 系统中文字体；不引入书法字体、在线字体或新图标字体 |
| 字号层级 | 基线下卦名22px（1.375rem），分区标题和原文17px（1.0625rem），普通正文／按钮15px（0.9375rem）；来源沿用现有比例 |
| 行高 | 普通正文1.7，原文1.85；长原文自然换行，不裁切主要内容 |
| 间距／形状 | 页面横向32rpx，卡片内边距28rpx、间距24rpx、圆角20rpx；按钮圆角14rpx |
| 交互反馈 | 复用现有按下、禁用和折叠“＋／−”；折叠标题整行可点 |
| 卦形 | 复用原有阴阳爻比例、线宽及颜色；卦头小图用于展示 |

### 3.2 新元素的最小表达

- 目录条只保留“阅读目录”和必要展开标识；面板使用相同背景、字体、分隔线及文字按钮，不增加彩色分类卡或重复卦图。
- 六爻沿用现有阅读卡片与折叠标题。爻辞、小象和来源在同一条目内，不层层套卡片；初始只露六行爻名。
- 上一项／下一项为并列的次级按钮，目标卦名在按钮内自然换行；“观察变化”沿用现有主按钮。页尾操作不悬浮遮挡正文。
- 界面不出现版本徽章、学习进度、推荐区、宣传横幅、装饰插画、背景纹理、额外阴影或与阅读无关的图标。
- 不重复介绍计算、开发、审核或本版功能。目录、来源、错误提示各只保留完成操作需要的短文案。

### 3.3 易读与触控

目录入口、爻条目及翻页按钮沿用至少48px高的主要触控区域；并列和换行布局不得压缩成难以点击的小字。展开、禁用和选择状态须有文字或符号表达，不只依赖颜色。提供匹配当前爻名／章节的可访问名称与展开状态，面板关闭后焦点回到合理位置。

检查320、375、390、430代表宽度，以及放大字体、长卦名和长原文；目录标题不被遮挡，底部控件避让安全区，面板内容可达。沿用正文可读对比要求，普通正文对比度目标4.5:1；不以加入更多色彩替代清晰层级。仅截图可见不能代表完整读屏或无障碍验收。

## 4. 实现边界与数据使用

以下为本版职责边界，各项实际实现及验证状态见[开发计划](development-plan.md)。

| 位置 | 本版职责 |
| --- | --- |
| `pages/atlas/index` | 保留现有检索；点击时先完成待刷新搜索，再按最新结果传递当前卦及有序结果快照 |
| `pages/detail/index`（新增） | 编号入口、目录、页尾翻阅、当前阅读状态与观变衔接 |
| `components/reading` | 复用卦头、经传与折叠；按明确入口启用六爻，避免影响生成／分析页 |
| `components/source-panel`、`hexagram-shape` | 复用来源展示和卦形，不另复制一套 |
| `state/` | 当前查阅上下文及关联观变会话，只在内存保存 |
| `domain/`、`data/` | 沿用纯计算及既有本地内容；不放页面滚动或wx调用 |

- 页面按当前卦ID读取`HexagramContent.yao`、`specialEntries`及原有来源。接口以[实际类型](../miniprogram/domain/types.ts)为准，不增加重复正文、预生成HTML或另一套内容索引。
- 连续阅读只需要有序结果ID、当前位置、是否筛选及当前页展开／滚动状态，不保存每卦历史，不引入持久化或通用状态框架。
- 卦编号、路由和外部上下文做入口校验；内部已确定的数据不重复防御，不用默认值掩盖资料或路由错误。
- 目录面板使用原生`page-container`，关闭及返回遵循§2.3的平台边界。目录关闭、目标展开并完成渲染后，再测量目标位置与实际吸顶条高度并定位；避免硬编码正文高度、延时猜测或重试循环。目录定位使用当前页面内的章节／爻位标识。
- 本版涉及的原文、卦头摘要、意象与整体含义正文使用原生`text`及`user-select`实现选取，并保留换行与段落分隔；意象与整体含义的全部正文共用一个可选取文本节点，支持跨句、跨段选取复制；不能以现有`view selectable`写法作为已支持的依据。属性与限制见[微信官方 text 说明](https://developers.weixin.qq.com/miniprogram/dev/component/text.html)。
- 每页首节点使用`page-meta root-font-size="system"`，字号统一用rem跟随用户的微信字体设置；详情页保留原有面板打开时的页面滚动控制。属性依据[微信官方 page-meta 说明](https://developers.weixin.qq.com/miniprogram/dev/component/page-meta.html)，实际字体与各宽度效果分别验证。
- 同页换卦时，阅读组件及来源组件内部的展开状态一并重置，不能只更新正文和引用而保留上一卦的来源展开状态。
- 复用现有读取组件时明确区分图鉴详情与生成／分析场景。目录若仅详情使用，留在该页；仅提取实际复用的部分，不引入重型UI库。
- 全部功能使用原生Page、Component、WXML、WXSS及TypeScript，资料随包可离线读取。运行包仍限`miniprogram/`，测试、文档、工具、审核档案不入包。

## 5. 继承的产品与资料基线

### 5.1 学习定位与资料

产品展示原典中的文字，辅助识卦、读辞和观察变化，不生成个人运势、主爻判断或吉凶决策。经传、爻辞及特殊条文只展示原文；既有意象与整体含义继续展示，白话、注记和审核留在内容档案。

### 5.4 数字输入与取余

三个字段依次为下卦数、上卦数、变爻数。输入先去首尾空白，只接受含非零位的ASCII十进制数字串；允许前导0，拒绝空、全0、负数、小数、正号、指数、字母、内部空白及全角数字。

按字符迭代`r = (r × 10 + digit) % divisor`，分别对8、8、6取余；余0对应8、8、6。不得把整个字符串转为Number、把三数相加或加入时间／随机数。运行算法额外空间O(1)，BigInt只用于开发测试独立参照。数字模式始终只允许计算出的唯一固定爻，领域入口同样校验。

### 5.5 变爻与生成流程

手动／图鉴观变允许0～6爻；集合只含1～6整数，去重排序。相对本卦同时翻转所选位，未选位不变；`changedMask = originalMask XOR OR(1 << (p-1))`。零变保持本卦，全变翻转六位，同一集合变两次复原。

爻名按本卦阴阳和位置决定：阳用九、阴用六，位置1为初、6为上，其余为二三四五。分析展示本卦所选爻辞及小象，不替换为变卦同位爻辞；用九／用六独立展示，不判定占断依据。手动／数字生成仍先读本卦，数字爻不可改选；新生成清空旧结果，返回保留当前有效会话。非法观变路由明确提示重新生成，不默认乾卦。

### 5.6 图鉴检索与速查

图鉴支持简繁卦名、全称、登记别名、拼音、首字母和精确卦序；规范化大小写、声调、空格与ü输入变体。数字只精确匹配卦序；关键词、上卦、下卦取交集，结果按卦序排序。输入延迟150ms刷新且不回写组词，清除只去关键词，重置清空全部条件。条件与滚动位置在本次内存保留；无结果保留输入与筛选并显示明确提示。

八卦速查保持两行八卦选择、类别筛选、卦性置顶；展示课堂8类、五行、颜色与两栏生克。相同值去重，不重新加回来源／体系说明小字、先天数或先天方位；完整档案仍保留。
