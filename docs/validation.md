## 离线检查与未通过项

应用代码未使用 wx.request、云服务、登录、存储或远程字体/图片，资料和元数据随包。工具的 Network → Offline 预设下，已加载的乾卦正文及来源可以打开；继续进入变爻页时页面未加载。实际错误包含：

```text
Failed to execute 'send' on 'XMLHttpRequest': Failed to load
'http://127.0.0.1:10138/apihelper/assdk?...'
net::ERR_INTERNET_DISCONNECTED
```

随后出现组件未找到错误。证据表明此预设同时阻断了开发者工具本地 SDK 通道；不能据本轮结果判定实体包完整离线通过。已恢复 Online 并重新编译，保留“真实断网下完整流程、离线重新进入”待办；没有为了迎合模拟器而改变随包结构或伪造离线通过记录。

未执行：实体 iOS/Android、实际断网重进、原生 touchcancel/系统触摸中断、横竖尺寸变化、放大字体、实体键盘遮挡和性能目标测量。未开展压力测试、大规模 UI 自动化或体验版上传。
