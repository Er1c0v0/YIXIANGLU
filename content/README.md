# 内容源与增量构建

| 路径 | 用途 |
| --- | --- |
| `hexagrams/01.json`～`64.json` | 每卦正文、意象与注记 |
| `reviews/01.json`～`64.json` | 同编号卦的逐条审核，含原文、说明与爻位档案 |
| `reviews/methods.json` | 共用核对流程、日期与共同问题 |
| `search.json`、`reviews/search.json` | 64卦检索词、拼音、结构关联与逐条审核 |
| `imagery.json`、`elements.json`、`reviews/trigrams.json` | 八卦对应、生克与逐条审核 |
| `sources.json` | 全库采用版本和对校版本 |
| `manifest.json` | 自动生成的版本、计数及待审清单 |

卦ID、正文ID和审核ID保持稳定。manifest.json与miniprogram/data/下的content.ts、search.ts、trigrams.ts、sources.ts由构建器生成，不手改。检索、速查与来源模块独立于正文模块，页面不联网取资料。


审核记录的`method`必须指向已登记流程；流程只含`checkedBy`、`checkedAt`及共同`issues`，不提供审核状态默认值。每条记录明确保存ID、主体哈希、各项状态、去重后的`checkedRefs`及独有`issues`；展开时共同问题与独有问题合并。构建与测试通过`scripts/content-lib.mjs`的`readReviewFiles`按卦序读取，再由`expandReviews`展开。独立复核应新建对应流程并更新受影响记录，不批改共享流程来冒充整批重审。

界面仅展示经传、爻辞与特殊条文原文，保留简短意象和整体含义。既有白话、爻位说明与审核记录原样留档；新原文无需另写白话，省略 explanation、explanationRefs，其审核 explanationStatus必须为 not-applicable。留档爻位说明及审核ID如有则成对提供。

新增资料的顺序：登记版本与段落定位 → 录入每卦卦辞、彖、大象、下至上六爻及小象 → 实际核对 → 记录审核对象哈希与真实状态 → 运行 `npm run build:content` 和 `npm run check`。新增条目可以待审，但不能伪造通过。修改已核对对象或来源版本会使旧 subjectHash失效，必须重新核对受影响条目；构建器不会刷新审核或批准资料。哈希算法见 scripts/content-lib.mjs。

已确认显示异常而需通写的字形，应逐条对照来源，记录原字、替换字、依据及实际核对范围；保留正文notes和审核issues中的旧记录，仅更新受影响条目的哈希。显示修正不能提高影印或独立复审状态。2026-10-22的蒙及另外四种异常字形处理见资料核对，后续不要对全库自动做繁简或异体字替换。

`npm run check:content`报告计数和待审数量；每卦必须具备15个必需原文块，乾坤各另有2个特殊原文块。新增检索须覆盖64卦，八卦须覆盖课堂8类及4类扩展资料，相生/相克各5条；来源、逐条审核和主体哈希均须有效。构建器显式识别根目录和审核目录的文件类别，未知JSON类别拒绝构建。`npm run check:content:release`另行要求完整资料及必需影印、独立复核和展示说明审核通过；不能以开发检查通过冒充发布通过。其他PRD发布要求另验。

结构版本为3，版本格式为 schemaVersion.内容哈希前12位；完整SHA-256覆盖正文、来源、展开后的审核记录、检索、意象和生克。新资料主体为去掉reviewId后的整条记录，结合所引用来源对象计算哈希；检索还纳入别名引用。旧正文主体规则不变，新增资料不会重算或批准旧审核。相同源重复构建应得到完全相同产物。

当前六批已录入64卦、964块，后续审核与资料整理见 [开发计划](../docs/development-plan.md)。来源采用四库本电子录文及普通《周易》电子对校版本，旧五卦采用版本保留；具体异文、版本与审核进度见 [资料核对](../docs/content-review.md)。卷页oldid只固定编排，不冻结嵌页；访问日、摘录文本和主体哈希共同记录实际采用范围，不能将电子对校称为影印核准。

测试会自动检查全部已录入资料与随包产物，后续不需修改批次数量、缺卦ID或逐段抄写正文到测试中。独立64组合、4096变化、关键数字/会话案例以及构建器拒绝无效资料的检查继续保留。

课堂表仅登记为“PRD所载课堂资料转录”，无原照片和教材页码，也无外部网址。每条对应关联体系和段落；先天/后天方位分开，八门注明奇门相关课堂对应，季节原词保留，颜色允许并列。常用读音由编辑核对，重点多音字关联字典；无依据别名留空。新资料独立复审与说明待审计数单列于清单，电子核对不等于纸本核准。

各来源按自身rightsNote显示许可与整理说明，不统一套用许可或标点声明。维基文库录文保留贡献者署名和页面条款；课堂转录不宣称原材料许可。代码许可尚未指定。
