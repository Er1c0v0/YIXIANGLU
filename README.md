# 易象录

微信原生 TypeScript 学习小程序，本地资料随包使用，无登录或后端。已支持手动组合、数字生成、阅读、变爻分析、64卦搜索筛选与八卦速查。首版功能和两台用户设备实测已完成，交付事实见[验证记录](docs/validation.md)。

[第二版](docs/PRD.md)已实现图鉴独立查阅、六爻直接阅读、目录定位与连续翻阅，并与观变衔接；完成代码与测试精简、小屏和放大字体适配。2026-10-23用户确认整段复制及剩余真机验证通过，程序版本更新为0.2.0。实际验收与交付结果见[验证记录](docs/validation.md)，后续安排见[开发计划](docs/development-plan.md)。

## 使用与开发

使用 Node.js 22 或更高版本，在仓库根目录运行：

```sh
npm ci
npm run build:content   # 构建随包资料与版本清单
npm run check          # 内容、类型、独立算法及关键交互检查
```

微信开发者工具导入仓库根目录（`project.config.json`所在位置），运行目录为`miniprogram/`，启用TypeScript编译；无需“构建npm”。AppID由项目负责人配置，私人设置`project.private.config.json`不纳入Git。若仍报告根目录找不到app.json，使用“项目 → 重新打开此项目”。

单项命令：`npm run typecheck`、`npm test`、`npm run check:content`。`npm run check:content:release`检查首版完整性、电子初核及已确认待修问题。用户已取消文献人工复审和真机性能计时要求；待审记录继续留档，不伪报通过。

## 功能约定

- 阅读：卦辞、意象与整体含义默认展开，彖传、大象传默认折叠；经传和爻辞只显示原文，白话留档。独立详情按初爻至上爻提供六个折叠条目，可同时展开；每条依次展示爻辞、小象和共同来源，乾坤的用九／用六仍独立展示。生成与分析页不增加整套六爻。
- 独立查阅：图鉴点卦直接进入详情；可用`/pages/detail/index?id=1`按编号打开，非法编号提示返回图鉴。点击页尾“观察变化”才开始选爻，返回保留阅读状态，同页再次观察继续有效选择；离开详情后不保存观察历史。手动与数字生成仍先读本卦再选爻。
- 目录与翻阅：详情目录展开并定位到章节或爻位；页尾按全量卦序或进入时的筛选结果快照在同页切换，首尾不循环。换卦重置阅读展开与本页观变关联，返回图鉴保留原条件、结果和位置；失效上下文提示返回图鉴，不扩大阅读范围。
- 图鉴：支持简繁名称、全称、登记别名、拼音、首字母和精确卦序；上下卦与关键词取交集。清除保留筛选，重置恢复全部；仅条件生效时显示数量，条件与滚动位置只在本次内存保留。
- 八卦速查：卦性置顶，展示课堂8类、五行、颜色及两栏生克；不显示来源、说明小字或先天数/方位，完整资料继续留档。
